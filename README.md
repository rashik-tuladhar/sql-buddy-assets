# SQL Buddy assets

**SQL Buddy** by RashikTuladhar, a VS Code extension for T-SQL, MySQL and PostgreSQL:

- VS Code Marketplace: https://marketplace.visualstudio.com/items?itemName=RashikTuladhar.sql-buddy
- Open VSX: https://open-vsx.org/extension/RashikTuladhar/sql-buddy
- Website: https://rashik.com.np/sql-buddy

This repository is the one linked from the extension's page. The extension's source is private; this repository holds the screenshots and animations shown on its Marketplace page. They are made with demo data only, by `npm run media` in the extension's repository.
